# Страница кандидата — разработчик / AI-автоматизация

Русскоязычный одностраничный сайт без бренда, телефона, email и WhatsApp. Вопросы — только в чате HeadHunter.

## Публикация

GitHub Pages публикует корень ветки `main`. Статические HTML/CSS/JS без сборки, внешних шрифтов, аналитики и зависимостей.

Для локального просмотра:

```sh
python3 -m http.server 54324 --bind 127.0.0.1
```

## Редактирование

- `config.js`: вопросы, варианты, обязательность, текст задания и режим работы.
- `index.html`: инструкция, описание роли, условия, структура блоков.
- `styles.css`: оформление и адаптивность.
- `app.js`: анкета, проверка файла, предварительный просмотр и подключение приёма.
- `client.mjs`: предоставленный модуль серверной загрузки; GitHub-ключей в нём нет.

Поддержаны типы вопросов `text`, `textarea`, `select`, `radio`, `checkboxes`. При изменении подписи сохраняйте постоянный `id` вопроса.

## Текущий режим: предварительная версия

`applicationMode: 'preview'`. Кнопка проверяет ответы и открывает локальный предварительный просмотр. Ответы и ZIP не отправляются и не сохраняются в браузерном хранилище. Выбранный файл доступен до обновления или закрытия страницы. В интерфейсе явно написано, что приёма реальных заявок пока нет.

Тестовое задание ещё не утверждено. Вопросы — заготовка для последующего редактирования. График переведён из 14:00 Arizona (UTC−7) в 00:00 МСК (UTC+3) следующего календарного дня; 00:00–08:00 — ориентир для восьми рабочих часов без учёта перерывов. Оплата и окончательные рабочие правила не выдуманы.

## Включение реального приёма

После утверждения владельцем текста задания и согласия:

1. Заполнить `assignment.description`, установить `assignment.published: true` и заменить сопутствующие заготовки в HTML.
2. Заполнить `consentText` утверждённым текстом и установить `applicationMode: 'live'`.
3. Проверить доступность backend, CORS, внешний диск и сохранение синтетической заявки до открытия приёма.

Одного переключателя недостаточно: без опубликованного задания и текста согласия приложение останется в режиме просмотра. Реальный успех показывается только после серверного `status: 'submitted'`. Загрузка идёт частями, для повтора сохраняется прежняя сессия. Лимит ZIP — 2 ГиБ; максимальный размер не означает проверенную скорость или полный нагрузочный прогон.

API настроен на ранее подготовленный сервис. Его автономный запуск после перезагрузки Mac зависит от отдельного нерешённого вопроса доступа macOS к внешнему диску. Настройки сервера и автозапуска эта страница не меняет.

В public-репозитории нет заявок, архивов кандидатов, содержимого реестра, GitHub-токенов или внутренних документов.
